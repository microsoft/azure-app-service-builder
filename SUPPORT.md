# Support

## Product feedback and questions

Use [GitHub Issues](https://github.com/microsoft/azure-app-service-builder/issues) for general product feedback, feature requests, reproducible bugs, and questions that can be discussed publicly. Feedback is welcome across the product. [Search existing issues](https://github.com/microsoft/azure-app-service-builder/issues?q=is%3Aissue) first, then select the appropriate [feedback form](https://github.com/microsoft/azure-app-service-builder/issues/new/choose).

App Service Builder is in Private Preview for development/test, not production. This repository is public, but feedback intake and plugin installation do not grant preview access or establish service qualification.

## Temporary App Service Builder support

Official Azure Support onboarding for App Service Builder is not yet complete. Until it is, use the [Support request form](https://github.com/microsoft/azure-app-service-builder/issues/new?template=04-support-request.yml) for setup, usage, and troubleshooting help that can be discussed publicly.

Describe what you are trying to do, where you are blocked, and what you have already tried using minimal, sanitized examples. Do not attach raw logs, network captures, or diagnostic bundles. If a problem requires confidential information, share only the non-sensitive symptom and ask maintainers for an appropriate private next step; do not post the confidential details here.

This is a temporary, best-effort preview support channel, not an official Azure Support ticketing channel. It does not provide a response-time guarantee or an SLA.

## Azure service and account support

For other Azure services, urgent service problems, billing, or account access, consult [Azure support options](https://azure.microsoft.com/support/options/). Consult [Azure status](https://azure.status.microsoft/) for published service incidents. These options do not imply that App Service Builder has completed official support onboarding; use the temporary channel above for Builder-specific help.

This repository is not an Azure support channel, and opening an issue does not create an Azure support request. Azure support eligibility depends on the service and your support arrangements; this hub does not establish product support coverage, a response-time guarantee, or an SLA.

## Security and privacy

Do not report suspected vulnerabilities in an issue or comment. Follow [SECURITY.md](SECURITY.md) and [Microsoft's private security reporting guidance](https://aka.ms/SECURITY.md).

Treat everything submitted to GitHub as public, including titles and attachments. Do not post email addresses, account or contact details, credentials, subscription or resource IDs, customer data, or confidential diagnostics. Use minimal, sanitized examples instead. If sensitive information is posted accidentally, stop sharing it, revoke exposed credentials where applicable, and contact the appropriate private support or security channel. Editing a post does not guarantee removal from its history or copies.
